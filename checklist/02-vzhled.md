# Vzhled

**Týká se:** každého webu.

Tady je jen základ. Znaky, podle kterých se pozná web vygenerovaný AI, a jak se jich zbavit, chystáme jako samostatné repo.

- [ ] **VZH-1** Design system existuje jako soubor (třeba `design.md`) dřív, než agent začne generovat stránky. Bez něj si agent vymýšlí vzhled pokaždé znovu.
- [ ] **VZH-2** Web nemá typické znaky AI vzhledu: fialovo-modrý gradient, font Inter všude, čtyři karty v mřížce, stejné zaoblení všeho, mlhavé nadpisy, stock fotky, všude stejný fade-in.
- [ ] **VZH-3** Barvy jsou pojmenované podle funkce (hlavní, chyba, pozadí), ne podle vzhledu (modrá-500).
- [ ] **VZH-4** V textu nejsou dlouhé pomlčky, dvoubarevné gradientové nadpisy ani emoji v nadpisech sekcí.
- [ ] **VZH-5** Aspoň jedna věc je schválně nekonvenční. Jinak je web čistý, ale zapomenutelný.
- [ ] **VZH-6** Když web má tmavý režim, je dotažený do všech stavů. U jednoduché landing page ho řešit nemusíš, špatný tmavý režim je horší než žádný.
