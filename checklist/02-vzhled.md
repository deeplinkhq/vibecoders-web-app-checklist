# Vzhled

**Týká se:** každého webu a aplikace.

Tady je jen základ pro práci s vzhledem k webu. Znaky, podle kterých se pozná web vygenerovaný AI, a jak se jich zbavit, chystáme jako rozšíření - sleduj https://filipobornik.cz newsletter.

- [ ] Design system existuje jako soubor nebo složka s referencemi (třeba `design.md`) aby agent měl jasný vzor
- [ ] Barvy jsou pojmenované podle funkce (hlavní, chyba, pozadí), ne podle vzhledu (modrá-500). [Barevné role Material]
- [ ] V textu nejsou dlouhé pomlčky, dvoubarevné gradientové nadpisy ani emoji v nadpisech sekcí. [Znaky AI textu]
- [ ] Aspoň jedna věc je schválně nekonvenční. Jinak je web čistý, ale zapomenutelný.
