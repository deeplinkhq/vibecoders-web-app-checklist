# Provoz

**Týká se:** čehokoli, co má běžet déle než týden.

## Hlídání

- [ ] Je zapnuté hlídání dostupnosti, které se ozve, když web spadne.
- [ ] Když jde o aplikaci: chyby na produkci se zaznamenávají a chodí o nich upozornění. Ověřeno schválně vyvolanou chybou, jinak se o pádu dozvíš od uživatele, nebo vůbec.
- [ ] Víš, jak dlouho se drží záznamy o chodu aplikace. Bývá to i jen hodina a chybu nahlášenou druhý den v nich nenajdeš.
- [ ] Záznamy ani hlášení chyb neukládají hesla, klíče ani osobní údaje.
- [ ] Upozornění chodí na e-mail, který někdo opravdu čte.
- [ ] První týden po spuštění je ověřené, že chodí zprávy z formuláře. Tiché selhání doručování je nejčastější skrytá porucha.

## Peníze

- [ ] Hosting, databáze a placené služby mají nastavený rozpočet nebo upozornění na útratu. Účet za zneužitou funkci přijde až na konci měsíce.
- [ ] Doména má zapnuté automatické prodloužení a platební karta je platná.

## Pravidelná údržba

- [ ] Jednou měsíčně 15 minut: formulář funguje, vyhledávač nehlásí chyby, doména neexpiruje, aktualizace jsou prošlé, zálohy běží.

## Když se něco pokazí

- [ ] Je sepsané, co dělat, když web spadne nebo unikne klíč: kdo to řeší, jak vrátit verzi, jak vyměnit klíče a jak dát vědět uživatelům.

## Předání

- [ ] README projektu říká, kde web běží, kde jsou účty (bez hesel), kam chodí formulář, kde jsou zálohy a jak vrátit předchozí verzi. Za půl roku to nebudeš vědět ani ty.
