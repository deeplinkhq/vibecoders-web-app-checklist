# Provoz

**Týká se:** čehokoli, co má běžet déle než týden.

## Hlídání

- [ ] **PROV-1** Je zapnuté hlídání dostupnosti (UptimeRobot a podobně, základ zdarma).
- [ ] **PROV-2** Upozornění z hostingu (neúspěšné nasazení, doména), Search Console a hlídání dostupnosti chodí na e-mail, který někdo opravdu čte.
- [ ] **PROV-3** První týden po spuštění je ověřené, že chodí zprávy z formuláře. Tiché selhání doručování je nejčastější skrytá porucha.

## Doména

- [ ] **PROV-4** Doména má zapnuté automatické prodloužení a platební karta u registrátora je platná.

## Pravidelná údržba

- [ ] **PROV-5** Jednou měsíčně 15 minut: formulář funguje, Search Console je bez chyb, doména neexpiruje, aktualizace závislostí jsou prošlé přes preview.
- [ ] **PROV-6** Když projekt má databázi: zálohy běží a poslední je čerstvá.
- [ ] **PROV-7** Když se data z analytiky dají číst agentem (třeba přes Google Analytics MCP, jen pro čtení): po pár týdnech provozu je nech projít a navrhnout úpravy.

## Předání

- [ ] **PROV-8** README projektu říká, kde web běží, kde jsou účty (bez hesel), kam chodí formulář, kde jsou zálohy a jak vrátit předchozí verzi. Za půl roku to nebudeš vědět ani ty.
