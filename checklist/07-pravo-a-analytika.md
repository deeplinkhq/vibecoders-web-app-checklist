# Právo a analytika

**Týká se:** každého webu provozovaného v České republice.

Nejsme právníci a tohle není právní poradenství. Ber to jako seznam otázek, které si máš položit.

## Cookie lišta

- [ ] Když web nepoužívá jiné než technické cookies, cookie lištu nemá. Úřad pro ochranu osobních údajů to říká přímo.
- [ ] Když lišta je: souhlas se dává předem a před souhlasem se nenačte nic, co sleduje návštěvníky. Na tomhle padá většina webů.
- [ ] Když lišta je: odmítnout jde stejně snadno jako souhlasit, už na první obrazovce. Souhlas jde kdykoli odvolat.
- [ ] Fonty, mapy, videa a CAPTCHA z cizích služeb jsou zkontrolované, jestli nepřidávají sledování. Často jsou jediný důvod, proč web lištu potřebuje.

## Formulář a osobní údaje

- [ ] U formuláře je krátká věta o tom, k čemu údaje slouží, a odkaz na zásady zpracování, viditelné před odesláním.
- [ ] Kontaktní formulář nemá zaškrtávátko „souhlasím se zpracováním". Údaje zpracováváš, abys mohl odpovědět, k tomu souhlas nepotřebuješ.
- [ ] Je stanovené, jak dlouho se data z formuláře uchovávají (u dotazů běžně 1 až 3 roky).

## Zásady zpracování

- [ ] Zásady jsou samostatná stránka, odkázaná z patičky i od formuláře. Jsou povinné, jakmile web sbírá osobní údaje.
- [ ] Obsahují: kdo údaje zpracovává, jaké a proč, jak dlouho, které služby k nim mají přístup, jestli odcházejí mimo EU, jaká práva lidé mají a že si můžou stěžovat u ÚOOÚ.
- [ ] Vygenerované zásady jsou proškrtané a pravdivé. Nepravdivé zásady jsou horší než stručné pravdivé.

## Patička

- [ ] Když web provozuje podnikatel: v patičce je jméno, sídlo, IČO, údaj o zápisu do rejstříku a funkční e-mail.

## Prodej a účty

- [ ] Když web prodává spotřebitelům: obchodní podmínky jsou odkázané z patičky i před platbou.
- [ ] Když aplikace má uživatelské účty: uživatel si může účet smazat, nebo je napsané, jak o smazání požádat. Smazat se musí i data v navázaných službách.
- [ ] Když aplikace drží osobní údaje: víš, že únik dat se hlásí ÚOOÚ do 72 hodin od zjištění. Postup měj sepsaný předem.

## Newsletter

- [ ] Když web sbírá e-maily na newsletter: souhlas je samostatný, dobrovolný a dá se prokázat.
- [ ] Každá rozesílka má jasného odesílatele a funkční odhlášení.
- [ ] Na adresy z kontaktního formuláře nechodí newsletter. Tohle je reálně největší riziko celé sekce.

## Analytika

- [ ] Je vědomé rozhodnutí: analytika s cookies (víc dat, ale potřebuješ lištu), nebo analytika bez cookies, která lištu nepotřebuje.
- [ ] Analytika je uvedená v zásadách zpracování, i když je bez cookies.
- [ ] Měří se návštěvy, odkud lidé přišli a kolik z nich udělalo hlavní akci. Neměří se nic, podle čeho bys nic nezměnil.

## Přístupnost a zákon

- [ ] Je jasné, jestli se na web vztahuje zákon o přístupnosti (424/2023 Sb., účinný od 28. 6. 2025). Týká se e-shopů, bankovnictví, dopravy a dalších vyjmenovaných služeb, mikropodniky mají výjimku. Prezentační web s kontaktním formulářem tam nespadá.
