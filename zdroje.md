# Zdroje

Z čeho checklist vychází. Čísla a pravidla v položkách se dají dohledat tady.

## Podobné checklisty

- [Front-End Checklist](https://github.com/thedaviddias/Front-End-Checklist) a [frontendchecklist.io](https://frontendchecklist.io): nejznámější obecný checklist pro web.
- [vibe-coding-security](https://github.com/boxed-dev/vibe-coding-security): checklist před spuštěním pro aplikace postavené s AI.
- Produkční checklisty hostingů a databázových služeb, ze kterých jsme brali jen obecné principy.

## Bezpečnost

- [OWASP Top 10:2025](https://top10.owasp.org/2025) a rozbor [Vibe coding against OWASP Top 10](https://softwaremill.com/vibe-coding-against-owasp-top-10-2025/) od SoftwareMill.
- [OWASP Top 10 for LLM Applications 2025](https://genai.owasp.org/llm-top-10/)
- [Escape.tech: State of Security of Vibe Coded Apps](https://escape.tech/state-of-security-of-vibe-coded-apps)
- [UpGuard: Systemic Data Exposure in Supabase Apps](https://www.upguard.com/blog/everything-everywhere-systemic-data-exposure-in-supabase-apps) (10/2026): tisíce databází s daty čitelnými pro kohokoli.
- Veracode GenAI Code Security Report 2025, GitGuardian State of Secrets Sprawl 2026, studie o halucinovaných balíčcích z USENIX Security 2025.
- [Incident Replit](https://oecd.ai/en/incidents/2025-07-19-1eb1): agent smazal produkční databázi (7/2025).

## Testování

- [BugBug: How to Test a Vibe-Coded App](https://bugbug.io/blog/software-testing/how-to-test-a-vibe-coded-app/) (9/2026, text výrobce testovacího nástroje)

## SEO, rychlost a přístupnost

- Google Search Central: titulky, duplicitní adresy, strukturovaná data, robots.txt, AI funkce ve vyhledávání.
- [web.dev](https://web.dev): Core Web Vitals, fonty, obrázky.
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/), WebAIM Million 2026.
- [ogp.me](https://ogp.me): náhledy při sdílení.
- Dokumentace AI crawlerů OpenAI, Anthropic a Applu.

## Právo v ČR

- ÚOOÚ: doporučení k cookies (3/2023).
- Zákon 127/2005 Sb. o elektronických komunikacích, zákon 480/2004 Sb. o některých službách informační společnosti, § 435 občanského zákoníku, GDPR (čl. 13 a 33).
- Zákon 424/2023 Sb. o přístupnosti, výklad ČOI.
